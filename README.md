# Baby Ready UI Demo
Interactive tablet web prototype for new parents.

## Project Overview
This is a tablet-sized interactive UI prototype, designed for new parents to record baby-related information and track daily care tasks.
Built as a static web demo for UX portfolio.

## Features
- Tablet-first responsive interface
- Interactive UI elements
- Designed for new parent user group
